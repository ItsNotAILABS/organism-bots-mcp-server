# RETURN Agent Lineages

This release candidate reunifies historical ITSNotAI agent research as one governed runtime taxonomy inside NOVA Organism Bots MCP.

## Recovered lineages

- Mortal - bounded task/session worker
- Phantasma - ephemeral/stateless worker
- Undead - persistent identity across runtime termination
- Ghost - dormant checkpoint-backed agent
- Lich - identity anchored to an external protected store
- Zombie - degraded survival mode
- Phoenix - controlled reconstitution / upgrade cycle
- Swarm Undead - distributed continuity
- Cyborg - human-machine hybrid agency
- Ninja - browser/research phenotype
- Droid - embodied device agent

These are composable traits rather than mutually exclusive species. An agent can be `Undead + Ninja`, `Phoenix + Droid`, `Phantasma + Researcher`, or `Cyborg + Droid`.

## Governing rule

Cognition does not imply authority. Every consequential action remains governed by NEXUS / POCKET policy and scoped capabilities.

## Launch boundary

Use the existing launch levels: L0 draft -> L1 registered -> L2 runnable -> L3 proved -> L4 marketable. Recovered papers or workers are evidence of prior work, not automatic production readiness.

The archaeology for this release includes Undead and Cyborg papers in MedinaMemorySystems, Undead and Phantom packages/workers in LOOM, Phantasma implementations in Chimeria, Sonic Ninja / Vigil browser-agent materials in NOVA/AURO, and embodied execution surfaces in POCKET / PhoneAI.
